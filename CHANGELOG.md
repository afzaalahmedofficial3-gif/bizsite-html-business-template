# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-30

### Added

- Home page with hero, stats, trusted-by strip, services grid, about split
  section, why-choose-us features, portfolio grid, pricing, testimonial
  slider, FAQ accordion, blog preview and CTA banner.
- About page with company story, values, team grid, animated counters and
  CTA banner.
- Services page with detailed alternating service blocks, a 4-step process
  section, pricing teaser, FAQ and CTA.
- Contact page with contact info cards, a validated front-end contact form
  (with success message), office hours and a map placeholder section.
- Shared sticky header with top bar, mobile hamburger menu and
  dark/light mode toggle (persisted in `localStorage`).
- Shared 4-column footer with newsletter form and front-end validation.
- Scroll-reveal animations, animated stat counters and a back-to-top
  button — all in a single small vanilla JavaScript file.
- Fully responsive layout (mobile, tablet, desktop) with accessible,
  semantic HTML5 and per-page SEO / Open Graph meta tags.
- Print-friendly, dependency-free codebase: no frameworks, no libraries,
  no CDN, no build step.
